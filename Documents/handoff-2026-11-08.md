### FAQ audio publishing

Publishing an FAQ now:

1. Generates English MP3 audio with Cloudflare Aura-2.
2. Uploads the MP3 to Vercel Blob.
3. Upserts the `faq_audio` database row.
4. Marks the FAQ as published.
5. Returns the published FAQ and its audio URL.

Republishing is safe because the deterministic Vercel Blob filename uses
`allowOverwrite: true`.

### Cloudflare integration

- Supports Cloudflare's OpenAI-compatible picker response:
  `result.choices[0].message.content`.
- Uses longer timeouts for Whisper and FAQ selection to support ESP32 requests.
- Aura-2 MP3 requests omit the unsupported `container: "none"` combination.

### ESP32 firmware

- Records 16 kHz mono WAV audio.
- Sends voice questions to `/api/ask`.
- Receives the approved FAQ answer and generated audio URL.
- Downloads and plays MP3 audio through the speaker.
- Uses the ESP-IDF trusted certificate bundle for HTTPS Vercel Blob downloads.
- Firmware was built and flashed successfully on `COM3`.

The tested local ESP32 address was `192.168.8.186`. The local backend computer
address used by the firmware was `192.168.8.170`.

## Deployment next steps

### 1. Push the merged code

From the repository root:

```powershell
git switch master
git push origin master
```

### 2. Configure Vercel

In the Vercel project, add these environment variables for **Production**:

```env
DATABASE_URL=
BETTER_AUTH_SECRET=
BETTER_AUTH_URL=https://your-domain.vercel.app
CF_ACCOUNT_ID=
CF_API_TOKEN=
BLOB_READ_WRITE_TOKEN=
DEVICE_TOKEN=
```

Do not upload or commit `.env`. Use the Vercel environment variable settings
for production secrets.

### 3. Deploy

In Vercel:

1. Import `EmeterioF/askNEU`.
2. Select the `master` branch.
3. Use build command:
   ```text
   npm run build
   ```
4. Use output directory:
   ```text
   dist
   ```
5. Deploy.

Make sure the production database has all Drizzle migrations applied before
testing FAQ audio publishing.

### 4. Run production checks

Open:

```text
https://your-domain.vercel.app/api/health
```

Then:

1. Sign in to the staff console.
2. Create or edit an FAQ.
3. Publish the FAQ.
4. Confirm it shows **Published**.
5. Confirm the **Play** control appears.
6. Play the generated audio.
7. Test unpublish and republish.

Also verify database health at:

```text
https://your-domain.vercel.app/api/health/db
```

### 5. Update the ESP32

Change the firmware backend base URL from the local computer address to the
deployed HTTPS URL:

```text
https://your-domain.vercel.app
```

Then rebuild and flash:

```powershell
cd D:\development\askNEU\firmware
$env:IDF_TOOLS_PATH = 'D:\development\esp'
Set-ExecutionPolicy -Scope Process Bypass
& D:\development\esp\frameworks\esp-idf-v5.4.4\export.ps1
idf.py -p COM3 flash monitor
```

The ESP32 must use the deployed HTTPS URL, not the computer's local IP.
Keep the ESP32 and backend `DEVICE_TOKEN` values identical.

## Final validation commands
